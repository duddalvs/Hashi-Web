Abra o hashi pelo iniciador

Na pasta do projeto, dê dois cliques em INICIAR.cmd. Ele inicia o sistema e abre o navegador automaticamente.

Mantenha a janela do iniciador aberta enquanto usar o hashi. Pode minimizá-la. Fechar essa janela desliga o sistema.

Depois que o iniciador mostrar “Servidor pronto”, use o botão abaixo.

Abrir o hashi O hashi precisa do servidor local para carregar as telas e acessar sua conta. Abrir somente este arquivo HTML não inicia o sistema.
